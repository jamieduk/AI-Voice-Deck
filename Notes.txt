Restart the AI Voice Desk service
=================================
https://github.com/jamieduk/AI-Voice-Deck

Accessable via http://localhost:8387/
# Set up a free secure cloudflare tunnel to get mic access in modern browsers!

The app runs as a systemd *user* service: ai-voice-desk.service

Restart (after code changes, e.g. provider fixes):
    systemctl --user restart ai-voice-desk.service

Equivalent helper from the project directory:
    npm run service:restart

Other useful commands:
    systemctl --user status ai-voice-desk.service --no-pager   # check it is running
    journalctl --user -u ai-voice-desk.service -f              # follow live logs
    systemctl --user stop ai-voice-desk.service                # stop
    systemctl --user start ai-voice-desk.service               # start

- systemctl commands use --user (not sudo) because it is a user service.
- If the unit is missing, run: npm run service:install
- Manual run without systemd: npm start



# To Start on boot
systemctl --user enable --now ai-voice-desk.service

# To stop it starting at boot (disable)
systemctl --user disable --now ai-voice-desk.service
